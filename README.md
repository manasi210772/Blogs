# Blogs

A personal food blog built with React, TypeScript, and Vite — my little corner of the internet for documenting restaurant visits, café finds, and the occasional food adventure.

## Features

- **Food Blog**: Honest reviews and stories from restaurants, cafés, and food experiences
- **MDX Support**: Blog posts written in Markdown with JSX components using MDX
- **Dark Mode**: Toggle-able light/dark theme (teal + warm cream palette) via CSS variables
- **Responsive Design**: Mobile-friendly layout built with Tailwind CSS
- **Decorative Background**: Ambient food-icon pattern (via `lucide-react`) rendered behind all pages
- **Type-Safe**: Full TypeScript support
- **Component Library**: Radix UI primitives (dialog, popover) plus custom UI components
- **Code Highlighting**: Syntax highlighting for code blocks with Rehype Prism Plus

## Blog Content

Currently the site has one live category: **Food Blogs** (`/blogs/food`): 8 posts covering restaurant/café visits.
 
## Tech Stack

- **React 18.3** — UI library
- **TypeScript** — Type-safe JavaScript
- **Vite 7** — Build tool and dev server
- **Tailwind CSS 3** — Utility-first CSS framework
- **React Router DOM 6** — Client-side routing
- **MDX** (`@mdx-js/react`, `@mdx-js/rollup`) — Markdown with JSX support
- **Radix UI** — Headless UI components (dialog, popover)
- **Lucide React** — Icon library
- **Rehype Prism Plus** — Code block syntax highlighting
- **ESLint** — Code quality and formatting
